Simple installation

Get started in three steps.

You don't need a computer. You can download the APK directly on your Samsung or other supported Android phone.

01

Download the APK

Tap the Android download button above. GitHub may ask you to sign in because the source repository is private.

02

Install on your phone

Open the downloaded Break-Tracker-Android.apk file. If prompted, allow installation from your browser or file manager.

03

Start a break and go Home

Open the app, start a countdown, and press Home. Enable Picture-in-Picture access for Break Tracker in Android settings if needed.

Before installing: This is a testing APK distributed through GitHub, not the Google Play Store. Some Android security prompts are expected. If you have an older build, back up important Kitt records before uninstalling it; test builds may use different signing keys. The app loads the live website, so internet access is needed. If the direct download is unavailable, open the latest GitHub Release and check its Assets.
